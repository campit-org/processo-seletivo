# Processo seletivo · Desafios técnicos da Campit

Este repositório reúne os desafios técnicos do processo seletivo da Campit. Cada vaga tem uma pasta com o enunciado e os dados de que você vai precisar.

| Vaga | Desafio | Pasta |
|---|---|---|
| AI Engineer | Assistente de atendimento da Pedal Certo, uma rede de lojas de bicicletas | [ai-engineer/](ai-engineer/) |
| Web Dev full stack | Agenda da Patas, uma clínica veterinária | [web-dev/](web-dev/) |

## Como funciona

1. Leia o README da pasta da sua vaga. Ele traz o enunciado, o que esperamos de cada nível e como usar os dados.
2. Clone este repositório ou baixe só a pasta da sua vaga.
3. Desenvolva a solução num repositório público **seu** no GitHub. Não abra pull request neste repositório.
4. Você tem 7 dias a partir do envio do desafio. Quando terminar, mande o link do seu repositório para o mesmo contato que enviou o desafio. Dúvidas também vão para esse contato.

A Pedal Certo e a Patas são empresas fictícias, e todos os dados deste repositório também: nomes, e-mails, telefones, endereços e pedidos não pertencem a pessoas ou empresas reais.
